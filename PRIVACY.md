
HorizonFM — Privacy Policy

Effective Date: October 8, 2026
Developer/Contact: konos3

1. Information We Collect

HorizonFM is designed to be highly privacy-respecting. The bot only collects and accesses the minimum amount of data required to function:
• Server Information: Server/Guild Name and Server ID.
• User Count: The total number of members currently in the server.

2. How We Use Your Information

We use this data solely for operational functionality and basic bot statistics, specifically:
• To monitor how many total listeners and servers HorizonFM is active in.
• To display server-specific statistics to the bot owner for performance optimization.

3. Data Storage and Retention

• We do not use an external database to track your personal messages, user profiles, or voice activity.
• Server names and user counts are fetched dynamically via the Discord API. Any cached data is completely erased when HorizonFM leaves your server.

4. Data Sharing

We do not sell, trade, or share any collected server data with third parties under any circumstances, except if required by law.

5. Your Rights and Data Deletion

Since we do not store personal user data, there is no history to delete. However, if you want all server information removed immediately, simply kick HorizonFM from your server. For any questions, contact us at konos3
